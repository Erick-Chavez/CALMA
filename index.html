01 · CONOCE CALMA

Un sistema conectado para acompañar el tratamiento.

CALMA busca integrar tecnología, seguimiento y una red de apoyo en una sola experiencia, conectando el parche con una aplicación móvil mediante Bluetooth.

◉

Parche transdérmico

Sistema diseñado para la administración transdérmica del tratamiento prescrito y su seguimiento.

⌁

Conectividad

El parche se vincula con la aplicación para facilitar el registro y seguimiento del uso.

♡

Red de apoyo

Una función de emergencia permite notificar a los contactos previamente establecidos durante una alerta.

02 · ¿CÓMO FUNCIONA?

Del tratamiento al seguimiento.

CALMA conecta diferentes elementos para crear una experiencia de seguimiento más integrada.

01

Prescripción

El profesional de la salud establece el tratamiento y los parámetros correspondientes.

02

Parche

El paciente utiliza el parche transdérmico de acuerdo con las indicaciones establecidas.

03

Aplicación

La información del sistema se vincula con la aplicación mediante Bluetooth.

04

Red de apoyo

Ante una emergencia, el usuario puede activar una alerta para sus contactos previamente configurados.

03 · LA APLICACIÓN

Tu información, en un solo lugar.

La aplicación de CALMA permite consultar el historial de uso y visualizar información relacionada con el seguimiento del tratamiento.
